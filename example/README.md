# emoji_weixin example

[English](README.md) | [简体中文](README.zh-CN.md)

Demo chat app for the `emoji_weixin` package.

## Run

```bash
# From this directory
# Edit assets/config.json and set klipyApiKey if you need Klipy search
flutter pub get
flutter run                      # or -d chrome / macos / windows / linux
```

## Config

- [`assets/config.json`](assets/config.json) — local settings (`klipyApiKey`)
- [`assets/config.example.json`](assets/config.example.json) — sample template
