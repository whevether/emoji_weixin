## 运行

```bash
# 在本目录下
# 如需 Klipy 搜索，编辑 assets/config.json 填入 klipyApiKey
flutter pub get
flutter run                      # 或 -d chrome / macos / windows / linux
```

## 配置

- [`assets/config.json`](assets/config.json) — 本地配置（`klipyApiKey`）
- [`assets/config.example.json`](assets/config.example.json) — 示例模板
