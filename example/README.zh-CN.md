# emoji_weixin example

[English](README.md) | [简体中文](README.zh-CN.md)

`emoji_weixin` 的演示聊天应用。

## 运行

```bash
# 在本目录下
# 如需 Giphy 搜索，编辑 assets/config.json 填入 giphyApiKey
flutter pub get
flutter run                      # 或 -d chrome / macos / windows / linux
```

## 配置

- [`assets/config.json`](assets/config.json) — 本地配置（`giphyApiKey`）
- [`assets/config.example.json`](assets/config.example.json) — 示例模板
